# ☕ Java Programming Solutions

A curated collection of **45 standalone Java programs** solving a wide range of programming challenges — from foundational concepts to intermediate data structure problems. Each solution follows clean coding practices, is well-commented, and is structured for readability.

---

## 📖 Overview

This repository serves as a practical portfolio of Java problem-solving skills. Every solution is self-contained in a class named using the convention `Problem_X_ClassName`, making it easy to navigate and reference individual problems.

**Ideal for:** Java learners, coding interview preparation, and demonstrating core programming proficiency.

## 🧩 Key Concepts Covered

- **Core Java** — Variables, data types, operators, type casting
- **Control Flow** — `if/else`, `switch`, `for`, `while`, `do-while`
- **Methods** — Modular design, parameter passing, return values
- **Data Structures** — Arrays, ArrayLists, HashSets; sorting and searching
- **I/O** — `Scanner` input, `System.out.printf` formatting
- **Robustness** — Input validation, division-by-zero guards, null/empty checks, bounds handling

## 🚀 Getting Started

**Prerequisites:** Java JDK 8 or higher

```bash
# Clone the repository
git clone https://github.com/fahim-shahriar-sqa/java-problem-solving.git
cd java-programming-solutions

# Compile a specific solution
javac Problem_1_IntegerOrDecimalCheck.java

# Run it
java Problem_1_IntegerOrDecimalCheck
```
